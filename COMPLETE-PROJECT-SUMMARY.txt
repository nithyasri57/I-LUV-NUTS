┌──────────────────────────────────────────────────────────────────────────────┐
│ 🚀 HOW TO RUN                                                                │
└──────────────────────────────────────────────────────────────────────────────┘

STEP 1: Start Backend
  Terminal 1:
    cd nuts-main/backend
    npm start
  
  ✅ Output: Server running on port 5000

STEP 2: Start Frontend
  Terminal 2:
    cd nuts-main/frontend
    npm start
  
  ✅ Output: Opens browser at http://localhost:3000

STEP 3: Test the Application
  1. Browse products on homepage
  2. Click "Add to Cart" on any product
  3. View cart by clicking cart icon
  4. Update quantities or remove items
  5. Click "Checkout"
  6. Fill in customer information
  7. Select payment method
  8. Place order
  9. See confirmation message

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔗 API ENDPOINTS                                                             │
└──────────────────────────────────────────────────────────────────────────────┘

BASE URL: http://localhost:5000/api

PRODUCTS:
  GET    /products ..................... Get all products

CART:
  GET    /cart ......................... Get cart items
  POST   /cart/add ..................... Add item to cart
  PUT    /cart/update/:id .............. Update quantity
  DELETE /cart/remove/:id .............. Remove item
  DELETE /cart/clear ................... Clear cart

ORDERS:
  POST   /orders/create ................ Create new order
  GET    /orders/:id ................... Get order by ID
  GET    /orders ....................... Get all orders

PAYMENT:
  POST   /payment/process .............. Process payment

┌──────────────────────────────────────────────────────────────────────────────┐
│ 🐛 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

ISSUE: Images not showing
FIX: Ensure all images are in root nuts-main/ folder
     Check image filenames in backend/server.js

ISSUE: Port 5000 already in use
FIX: Change PORT in backend/.env to 5001 or other

ISSUE: Cart not updating
FIX: Check backend is running
     Open browser console (F12) for errors
     Verify API_URL in frontend/src/App.js

ISSUE: CORS errors
FIX: Ensure backend is running on port 5000
     Check CORS is enabled in server.js

ISSUE: npm install fails
FIX: Delete node_modules and package-lock.json
     Run npm install again
     Check Node.js version (v14+)
